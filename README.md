# Can Ali Rıza Dinç — Portfolio

Modern and responsive portfolio built with HTML, CSS and vanilla JavaScript.

## Publish on GitHub Pages

1. Upload `index.html`, `style.css`, `script.js` and the `images` folder.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save.

## Replace before publishing

- Replace `mail@example.com` with your real email.
- Replace the LinkedIn `#` link.
- Replace empty project links.
- Replace SVG preview files with real screenshots later.

The contact form currently validates input but does not send email.
